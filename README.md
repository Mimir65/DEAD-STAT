# DEAD//STAT — аналитика игроков Deadlock

Учебный проект курсовой работы.

## Технологии
- HTML5
- CSS3
- JavaScript
- Canvas API для графика
- GitHub Pages для публикации

## Разделы сайта
- Профиль игрока
- Аналитика
- Герои
- История матчей

## Запуск
Откройте `index.html` в браузере. Для публикации загрузите все файлы в корень GitHub-репозитория и включите GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

## Важно
Текущая версия использует демонстрационные данные. Поиск пока меняет отображаемый идентификатор и не получает реальную статистику из API. Для реальных данных потребуется подключить источник статистики Deadlock.
